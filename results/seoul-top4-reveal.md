# 서울 TOP 4 — 순위 순차 공개 버전

- 1080×1920 / 24fps / 24초, 고해상도 원본 유지.
- 왼쪽에 1~4위 목록을 위에서 아래로 고정 표시.
- 시작 0.75초는 순위 숫자만 표시.
- 0.75초: 4. N서울타워 공개.
- 6초: 3. 창덕궁 공개, 4위 이름 유지.
- 12초: 2. 북촌 한옥마을 공개, 3~4위 이름 유지.
- 18초: 1. 경복궁 공개, 전체 이름 유지.
- 현재 순위는 금색으로 강조.
- FilmCraft 내장 그래픽과 타임라인으로 편집. H.264 High CRF 16 직접 출력, 별도 저용량 재압축 없음.
