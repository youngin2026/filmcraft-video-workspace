# 서울 TOP 4 — 검수용 영상 초안

- 24초, 540×960 세로, 24 fps
- Supabase MCP API에서 조회한 서울 기획 기준
- FilmCraft 0.20.1로 타임라인 편집, 확대 키프레임, 한글 그래픽, 페이드, H.264/AAC 출력
- 사진 16장 / 내레이션 없음 / 직접 합성한 간단한 배경음
- 순위는 기획 배열의 4→1 순서이며 객관적 평가 순위가 아닙니다.
- 러프컷이며 장소 식별·자막·구성은 최종 제작 전 검수 대상입니다.
